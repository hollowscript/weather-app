A Python desktop app that displays real-time weather data for any city.
Built With

Python
PyQt5 — desktop GUI
WeatherAPI — weather data

Features

Search weather by city name
Displays temperature (°C), weather condition, and emoji icon
Handles common API and network errors

Setup

Clone the repo

git clone https://github.com/hollowscript/weather-app.git
   cd weather-app

Install dependencies

pip install pyqt5 requests

Add your API key in Weather App.py

api_key = "your_api_key_here"
Get a free key at weatherapi.com

Run the app

python "Weather App.py"
Usage
Enter a city name and click Get Weather.
